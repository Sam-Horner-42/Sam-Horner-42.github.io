Cookie Conquest.

A strategy roguelike about gambling your way across the Cookie Kingdom. Roll dice to land inside a target range and capture each capital. Miss, and you lose everything you wagered.

Overview

Risk versus reward, one dice roll at a time.

We built Cookie Conquest within the time limit of Brackeys Game Jam 2025.2. Each capital sets a target range. You choose which dice from your limited pool to throw, and landing inside the range captures the capital. Any dice you roll are lost if you fail, and items can only be used once. Every turn is a decision about how much to risk.

The game is written entirely in Java and ships as a Windows executable with a bundled Java runtime, so players don't need to install anything.

Highlights

  • Dice-pool strategy

    Mixed dice types each give a different range of outcomes, so choosing which dice to roll is the core decision.

  • Roguelike stakes

    Failed rolls cost you the dice you wagered, and items are one-time use. Every conquest spends limited resources.

  • Map-based progression

    Capitals across the kingdom lock and unlock as you advance, and each one captured is flagged on the map.

  • Ships as one package

    A single download with a bundled JRE. Extract it and run the .exe.

My contribution

I wrote the majority of the logic code for this project while our team defined the UI borders and created the artwork.

What I learned
